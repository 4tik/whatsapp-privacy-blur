# Security & Privacy Policy

## Our Privacy Principles

Privacy and trust are the primary reasons **WhatsApp Privacy Blur** exists:

1. **Zero Tracking / Zero Analytics**: We do not collect, log, track, or analyze your browsing activity, messages, contacts, or preferences.
2. **Local-Only Execution**: The extension performs all operations directly in your browser. No data ever leaves your computer.
3. **No External Network Requests**: The extension makes 0 HTTP/HTTPS requests to any remote server or third-party service.
4. **Minimal Permissions**: The extension requests only `storage` and host access restricted solely to `https://web.whatsapp.com/*`.

---

## Scope of Protection

> [!NOTE]
> **CSS Blur is a Visual Screen Shield**
> The blur effects applied by this extension are rendered via CSS `filter: blur(...)`.
> This visual shield effectively prevents:
> - Casual **shoulder-surfing** in public places (airports, cafes, offices).
> - Accidental leakage during **screen sharing** (Zoom, Teams, Google Meet, Discord).
> - Unintentional captures in **screen recordings and screenshots**.
>
> **Important limitation:** CSS blur operates in the browser presentation layer. It does not encrypt WhatsApp Web messages or prevent extraction via Chrome Developer Tools (`Inspect Element`) by someone with direct access to your unlocked computer.

## Reporting a Vulnerability

If you discover a security concern or privilege escalation risk in this extension:
- Please **do not** open a public GitHub issue.
- Report the vulnerability responsibly by opening a private GitHub Security Advisory or contacting the maintainer directly.
- We will review and publish a fix promptly.
